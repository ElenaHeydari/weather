# 🌤️ Weather 

A clean and responsive weather application built with **HTML, CSS, and JavaScript**. It provides real-time weather information and a five-day forecast for cities around the world.

## ✨ Features

- 🔍 **City Search:** Search for weather information by city name.
- 🌡️ **Current Temperature:** View the current temperature of your selected city.
- 🌥️ **Weather Conditions:** Get a visual representation of current weather conditions.
- 💧 **Humidity:** Check the current relative humidity.
- 💨 **Wind Speed:** View the current wind speed.
- 🌡️ **Feels Like:** See the apparent temperature.
- 📅 **5-Day Forecast:** Get daily weather forecasts, including maximum and minimum temperatures.
- 🔄 **Temperature Conversion:** Switch between Celsius (°C) and Fahrenheit (°F).
- ⚡ **Live Weather Data:** Fetch up-to-date weather information using the Open-Meteo API.

## 🛠️ Technologies Used

- **HTML5** – Application structure
- **CSS3** – Styling and responsive layout
- **JavaScript (ES6+)** – Application logic and API integration
- **Open-Meteo API** – Weather and geocoding data

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ElenaHeydari/weather.git
```

### 2. Navigate to the project directory

```bash
cd weather
```

### 3. Run the application

Open the `index.html` file in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

## 🌐 API

This project uses the free [Open-Meteo API](https://open-meteo.com/) to retrieve weather information.

It uses two API endpoints:

- **Geocoding API:** Finds the geographical coordinates of a city.
- **Forecast API:** Retrieves current weather conditions and a five-day forecast.

No API key is required.

## 💻 Usage

1. Open the application in your browser.
2. Enter an English city name in the search field.
3. Click the search button to retrieve weather information.
4. View the current weather details and the five-day forecast.
5. Use the temperature toggle to switch between Celsius and Fahrenheit.
